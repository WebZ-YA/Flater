## 2. ضوابط الخصوصية والأمان
1. **عدم تسريب البيانات الطبية (Zero PHI in Telemetry)**:
   - يُمنع إرسال أسماء المرضى أو أرقام هواتفهم أو التشخيصات أو نتائج التحاليل إلى `Firebase Analytics`, `Crashlytics`, أو `stdout/logs`.
   - تُسجل فقط المعرفات غير الشخصية (`tenantId`, `operationId`, `errorCode`).
2. **عزل المستأجرين (Tenant Isolation)**:
   - تتحقق قواعد Firestore وCloud Functions من تطابق `tenantId` في المسار مع وثيقة `/tenants/{tenantId}/memberships/{request.auth.uid}` النشطة (`active == true`) و`Custom Claims`.
3. **حماية سجل التدقيق والعمليات المالية**:
   - مجموعة `audit_logs` مقفلة أمام التعديل والحذف من جهة العميل (`allow update, delete: if false;`) وتُنشأ عبر Cloud Functions أو الخادم المحلي الموثوق فقط.
   - الفواتير والمدفوعات محمية من التعديل الصامت؛ أي تعديل يتم عبر قيود تصحيحية/استرداد موثقة.
4. **تنبيه الامتثال القانوني والطبي (SRS §14)**:
   - استخدام Firebase وSQLite المشفر لا يعني تلقائياً استيفاء الامتثال القانوني المحلي (مثل HIPAA أو لوائح حماية البيانات الصحية الوطنية). يجب مراجعة المتطلبات القانونية وموقع استضافة بيانات Firebase (`firestoreRegion`) وعقود معالجة البيانات قبل الإطلاق التجاري الفعلي.
